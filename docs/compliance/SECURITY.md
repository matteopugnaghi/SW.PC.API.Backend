## 🔐 Reporting a Vulnerability

If you discover a security vulnerability in the Aquafrisch Supervisor SCADA/HMI system, please report it responsibly.

### Contact Information

| Method | Contact |
|--------|---------|
| **Email** | soporte@aquafrisch.com |
| **Phone** | +34 900 123 456 |
| **Subject** | `[SECURITY] Vulnerability Report - Aquafrisch Supervisor` |

### What to Include in Your Report

Please provide as much detail as possible:

1. **Description** of the vulnerability
2. **Steps to reproduce** the issue
3. **Affected components** (Backend, Frontend, PLC integration)
4. **Potential impact** (data exposure, unauthorized access, etc.)
5. **Any suggested fixes** (optional)

### Response Timeline

| Action | Timeframe |
|--------|-----------|
| Acknowledgment of report | **24 hours** |
| Initial assessment | **72 hours** |
| Action plan communication | **7 days** |
| Patch release | Based on severity |

### Severity Levels and Response

| Severity | Description | Target Fix Time |
|----------|-------------|-----------------|
| 🔴 Critical | Remote code execution, data breach | **48 hours** |
| 🟠 High | Authentication bypass, privilege escalation | **7 days** |
| 🟡 Medium | Information disclosure, DoS | **30 days** |
| 🟢 Low | Minor issues, hardening | **Next release** |

## 📜 Legal

We will not pursue legal action against security researchers who:

- Act in good faith
- Follow responsible disclosure practices
- Do not access or modify customer data
- Do not disrupt service availability
